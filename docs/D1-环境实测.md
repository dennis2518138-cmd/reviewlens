| SENSENOVA `deepseek-v4-flash` | ✗ 429 tpm/rpm | ✗ 429 | ✗ 429 rpm exhausted |

## 三、三个会咬人的坑（都实测过）

1. **代理 7897 挂着但 Clash 没开** → pip/curl/HTTP 全 000。已按 `memories/topics/env.md` 处理：命令前 unset。
2. **chromadb 默认 embedding 不能用**：它是英文 `all-MiniLM-L6-v2`，从 `chroma-onnx-models.s3.amazonaws.com` 下 79.3MB，实测 **36 KB/s**（约 35 分钟，还会时不时断）。中文评论用它召回也不对。
3. **官方 DeepSeek 直连不可用**，只能走 OpenAI 兼容中转；`langchain-deepseek` 的 `base_url` 参数可覆盖（已验）。

## 四、D3 的 embedding 方案（已定，别再试别的）

在 `models/bge-small-zh-v1.5/` 放了 ONNX 版，**不需要 torch / sentence-transformers**：

| 源 | 实测速度 | 结论 |
|---|---|---|
| `hf-mirror.com` | **21.4 MB/s**（94.8MB 4 秒下完） | ✔ 用这个 |
| `modelscope.cn` | 22.8 MB/s | ✔ 备选 |
| `huggingface.co` 直连 | http 000（不通） | ✗ |
| chroma 自带 S3 | 36 KB/s | ✗ |

实测推理：512 维，4 条 **8ms**；语义排序正确 ——
`sim(物流太慢, 快递很慢)=0.792` > `sim(物流太慢, 电池不耐用)=0.544` > `sim(物流太慢, 音质很好)=0.415`。

⚠️ 参数细节：bge 用 **CLS pooling**（`hidden[:,0,:]`）+ **L2 归一化**，输入要带 `token_type_ids`。
参考实现见 `scripts/embed_ref.py`，D3 请自己重写进 `app/embedding.py`（面试会问 pooling 和归一化）。
